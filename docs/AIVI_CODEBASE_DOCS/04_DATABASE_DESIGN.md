## 1. Complete Firestore Collection Inventory

The application utilizes 32 distinct Firestore document collections and subcollections. Below is the master schema specification detailing field names, data types, required/optional status, validators, access control rules, and anonymized example document shapes.

### 1.1 `tenants` Collection
* **Path Pattern:** `/tenants/{tenantId}`
* **Multi-Tenant Scoping:** Primary Tenant Entity Root Document [`firestore.rules`].
* **Write Actor:** Cloud Functions Admin SDK only (`provisionTenant`, `seedDemoCampus`) [`functions/src/index.ts`].
* **Read Actor:** Platform Admins, Tenant Staff, and verified Tenant Members (`hasTenant(tenantId)`) [`firestore.rules`].
* **Indexes:** Single document lookup by `tenantId`.

| Field Name | Type | Required | Default | Enum / Constraints | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `name` | `string` | Yes | N/A | Max 150 chars | Full legal name of educational institution |
| `code` | `string` | Yes | N/A | Unique slug, e.g. `demo-sunrise` | URL-safe tenant identifier code |
| `plan` | `string` | Yes | `"starter"` | `"basic"`, `"starter"`, `"pro"`, `"enterprise"` | Institutional subscription tier |
| `seats` | `number` | Yes | `500` | Integer >= 1 | Total student seat quota allowed |
| `seatsUsed` | `number` | Yes | `0` | Integer >= 0 | Current count of active enrolled students |
| `academicYear` | `string` | Yes | `"2025-26"` | e.g. `"2025-26"` | Current active academic cycle |
| `isDemo` | `boolean` | Optional | `false` | `true`, `false` | Identifies 1-click seeder demo campus |
| `seeded` | `boolean` | Optional | `false` | `true`, `false` | Flag indicating document was generated by seeder |
| `active` | `boolean` | Yes | `true` | `true`, `false` | Master tenant status toggle |
| `branding` | `map` | Yes | `{...}` | Map structure | Custom UI styling parameters |
| `branding.primaryColor` | `string` | Yes | `"#169C8F"` | Hex color code | Primary institutional brand color |
| `branding.accentColor` | `string` | Yes | `"#FF6D4A"` | Hex color code | Accent brand color |
| `branding.logoUrl` | `string` | Optional | `""` | Valid URL | Custom institutional logo image URL |
| `branding.loginHeadline`| `string` | Yes | `"Campus Portal"` | Text string | Custom headline displayed on branded login screen |
| `createdAt` | `timestamp` | Yes | ServerTimestamp | Timestamp | Document creation timestamp |
| `updatedAt` | `timestamp` | Yes | ServerTimestamp | Timestamp | Document last modification timestamp |

### 1.2 `profiles` Collection
* **Path Pattern:** `/profiles/{userId}`
* **Multi-Tenant Scoping:** Scoped by `tenantId` field [`firestore.rules`].
* **Write Actor:** Owner user (`isOwner(userId)`) or Cloud Functions Admin SDK [`firestore.rules`].
* **Read Actor:** Owner user, Platform Admin, or Tenant Staff matching `branchScope` [`firestore.rules`].
* **Indexes:** Composite: `(tenantId ASC, batch ASC)`, `(tenantId ASC, branch ASC)`, `(tenantId ASC, createdAt DESC)` [`firestore.indexes.json`].

| Field Name | Type | Required | Default | Enum / Constraints | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `userId` | `string` | Yes | N/A | Firebase Auth UID | Unique user identifier |
| `email` | `string` | Yes | N/A | Valid email | Registered user email address |
| `fullName` | `string` | Yes | N/A | Max 100 chars | Full legal display name of user |
| `role` | `string` | Yes | `"b2c"` | `"platform_admin"`, `"tenant_admin"`, `"coordinator"`, `"student"`, `"b2c"` | Master access control role |
| `tenantId` | `string` | Optional | `null` | Tenant Code string | Institutional tenant association |
| `enrollmentNo` | `string` | Optional | `null` | Alphanumeric | Student college registration / roll number |
| `branch` | `string` | Optional | `null` | `"CSE"`, `"ECE"`, `"ME"`, `"EE"`, `"CE"` | Academic department branch |
| `academicYear` | `string` | Optional | `null` | e.g. `"2025-26"` | Enrolled academic year |
| `graduationYear` | `number` | Optional | `null` | Integer, e.g. `2026` | Expected graduation year |
| `cgpa` | `number` | Optional | `null` | 0.0 to 10.0 | Academic Cumulative Grade Point Average |
| `placementStatus`| `string` | Optional | `null` | `"unplaced"`, `"placed"`, `"higher_studies"` | Current student placement status |
| `branchScope` | `array` | Optional | `[]` | Array of strings | Allowed branch access list for coordinators |
| `dpdpConsent` | `boolean` | Optional | `false` | `true`, `false` | Active Data Protection consent flag |
| `seeded` | `boolean` | Optional | `false` | `true`, `false` | Flag indicating seeder generation |
| `createdAt` | `timestamp` | Yes | ServerTimestamp | Timestamp | Profile creation timestamp |
| `updatedAt` | `timestamp` | Yes | ServerTimestamp | Timestamp | Profile last update timestamp |

### 1.3 `user_plans` Collection
* **Path Pattern:** `/user_plans/{userId}`
* **Multi-Tenant Scoping:** User-scoped B2C entitlement record [`firestore.rules`].

| `lifetime_interview_count` | `number` | Yes | `0` | Integer >= 0 | Lifetime Free plan interview prep count |
| `lifetime_promotion_count` | `number` | Yes | `0` | Integer >= 0 | Lifetime Free plan promotion readiness count |

| `monthly_reset_date` | `timestamp` | Optional | `null` | Timestamp | Date when monthly counter resets |
| `paid_until` | `timestamp` | Optional | `null` | Timestamp | Subscription expiration date |
| `trial` | `boolean` | Optional | `false` | `true`, `false` | Active trial flag |

### 1.4 `analysis_results` Collection
* **Path Pattern:** `/analysis_results/{docId}`
* **Multi-Tenant Scoping:** Scoped by `userId` and optional `tenantId` [`firestore.rules`].
* **Write Actor:** Cloud Functions Admin SDK only (`careerAnalysis`, `saveAnalysisResult`) [`firestore.rules`].
* **Read Actor:** Owner user, Platform Admin, or Tenant Staff [`firestore.rules`].
* **Indexes:** Composite: `(userId ASC, analysisType ASC, createdAt DESC)`, `(tenantId ASC, createdAt DESC)` [`firestore.indexes.json`].

| Field Name | Type | Required | Default | Enum / Constraints | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `userId` | `string` | Yes | N/A | Firebase Auth UID | User who requested analysis |
| `tenantId` | `string` | Optional | `null` | Tenant Code string | Associated institutional tenant ID |
| `analysisType` | `string` | Yes | N/A | `"resume"`, `"job_fit"`, `"roadmap"`, `"interview"`, `"promotion"`, `"portfolio"`, `"linkedin_analyze"`, `"linkedin_optimize"` | Analysis module type |
| `overallScore` | `number` | Yes | `0` | Integer 0-100 | AI-computed overall score metric |
| `resultData` | `map` | Yes | `{...}` | Valid JSON Object | Structured JSON output from Gemini AI |
| `promptTokens` | `number` | Yes | `0` | Integer >= 0 | Input prompt token count |
| `completionTokens` | `number` | Yes | `0` | Integer >= 0 | Output completion token count |
| `estimatedCostUsd` | `number` | Yes | `0.0` | Float >= 0.0 | Estimated Gemini API cost in USD |
| `createdAt` | `timestamp` | Yes | ServerTimestamp | Timestamp | Analysis creation timestamp |

## 2. Firebase Cloud Storage Bucket Topology

All binary media, student resume PDFs, and export archives are stored in Cloud Storage under strict security rules [`storage.rules`]:

| Storage Path Pattern | Access Control Rules [`storage.rules`] | Purpose |
| :--- | :--- | :--- |
| `/tenants/{tenantId}/resumes/{userId}/{filename}` | Read: `isOwner(userId) \|\| isPlatformAdmin() \|\| isTenantStaff(tenantId)`. Write: `false` (Server Admin SDK only). | Stores student resume PDF documents uploaded to the Campus Resume Vault. |
| `/exports/{tenantId}/{filename}` | Read: `isPlatformAdmin() \|\| isTenantStaff(tenantId)`. Write: `false` (Server Admin SDK only). | Stores compiled bulk ZIP resume export packages generated by `exportResumePackage`. |
